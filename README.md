# GarageWise
A python based app that helps people maintain their vehicles, organize repairs and understand how much ownership is costing them.

## Planned Features
- Add and manage multiple vehicles
- Record maintenance and repair history
- Track parts and labor expenses
- Calculate upcoming maintenance intervals
- Display maintenance reminders
- View vehicle maintenance information on a dashboard

## Technologies
- Python
- Flask
- SQLite
- HTML/CSS

## Project Goal
Our goal is to develop an easy-to-use application that helps vehicle owners organize their maintenance records and avoid missing important services.
