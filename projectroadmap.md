
## Existing Python Code Research

### Project: Vehicle Maintenance Tracker
Source: https://github.com/brthurr/vehicle-maintenance

This existing Python project is similar to GarageWise.
It uses Flask to create a web application and SQLite
to store vehicle information.

The application includes maintenance history,
service reminders, and expense tracking.

The database.py file demonstrates how to organize
vehicle and service records, while app.py shows
how Flask handles application requests.

We could use this project as a reference when
developing GarageWise's database and maintenance
tracking features. We plan to develop our own
interface and adapt the functionality to our
project's requirements.
